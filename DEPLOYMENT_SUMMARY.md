```bash

# 3. Commit and push to GitHub
git add .

git push origin main

# 4. Go to Render Dashboard

# - Click "Apply"
```

## 📱 Update Your Flutter App

After deployment, update your Flutter app's API base URL:

```dart
// lib/config/api_config.dart
class ApiConfig {
  static const String baseUrl = 'https://your-service.onrender.com/api/v1';
  
  // Or use environment-based configuration
  static String get baseUrl {
    if (kReleaseMode) {
      return 'https://your-service.onrender.com/api/v1';
    }
    return 'http://localhost:8080/api/v1';
  }
}
```

## 🆘 Troubleshooting

### Build Fails
```bash

make docker-build

# View detailed logs in Render dashboard
```

### Service Won't Start
1. Check environment variables in Render dashboard
2. Verify Appwrite credentials
3. Check logs for error messages
4. Ensure health endpoint returns 200 OK

### Redis Connection Issues
1. Verify Redis service is running
2. Check environment variables are linked
3. Ensure both services in same region
