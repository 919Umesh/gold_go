This guide helps you deploy the updated Gold Go application after Redis removal.

## 🚀 Quick Deployment Checklist

- [ ] Update environment variables (remove Redis vars)
- [ ] Remove Redis service from Render dashboard
- [ ] Push updated code to repository

- [ ] Test all API endpoints

## 1. Render.com Deployment

### Step 1: Remove Redis Service

1. Log into [Render Dashboard](https://dashboard.render.com)
2. Navigate to your project
3. Find the Redis service (`gold-go-redis`)
4. Click **Delete Service**
5. Confirm deletion

### Step 2: Update Backend Service

Your backend service will automatically update when you push the new code:

1. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "Remove Redis dependency"
   git push origin main
   ```

2. **Render will automatically:**
   - Detect the changes
   - Remove Redis environment variables
   - Rebuild the application
   - Deploy the new version

### Step 3: Verify Environment Variables

In Render Dashboard → Your Backend Service → Environment:

**Required Variables:**
```
PORT=8080
APPWRITE_ENDPOINT=https://fra.cloud.appwrite.io/v1
APPWRITE_PROJECT_ID=<your-project-id>
APPWRITE_API_KEY=<your-api-key>
APPWRITE_DATABASE_ID=<your-database-id>
JWT_SECRET=<auto-generated-or-custom>
WORKER_COUNT=5
QUEUE_SIZE=100
```

**Remove These (if present):**
```
REDIS_HOST
REDIS_PORT
REDIS_URL
REDIS_PASSWORD
REDIS_DB
```

### Step 4: Monitor Deployment

1. Watch the deployment logs in Render
2. Wait for "Deploy succeeded" message
3. Check application health:
   ```bash
   curl https://your-app.onrender.com/health
   ```

Expected response:
```json
{"status":"healthy"}
```

## 2. Docker Deployment

### Local Docker Development

1. **Update your local files:**
   ```bash
   git pull origin main
   ```

2. **Remove old Redis containers:**
   ```bash
   docker-compose down -v
   ```

3. **Rebuild and start:**
   ```bash
   docker-compose up --build
   ```

4. **Verify:**
   ```bash
   curl http://localhost:8080/health
   ```

### Docker Production

If deploying to your own Docker infrastructure:

1. **Update environment variables** in your deployment configuration
2. **Remove Redis service** from your docker-compose or Kubernetes config
3. **Rebuild images:**
   ```bash
   docker build -t gold-go:latest .
   ```

4. **Deploy:**
   ```bash
   docker run -d \
     -p 8080:8080 \
     -e PORT=8080 \
     -e APPWRITE_ENDPOINT=https://fra.cloud.appwrite.io/v1 \
     -e APPWRITE_PROJECT_ID=your-project-id \
     -e APPWRITE_API_KEY=your-api-key \
     -e APPWRITE_DATABASE_ID=your-database-id \
     -e JWT_SECRET=your-secret \
     gold-go:latest
   ```

## 3. Verifying the Deployment

### Test All Critical Endpoints

```bash
# Set your base URL
BASE_URL="https://your-app.onrender.com/api/v1"

# 1. Health Check
curl $BASE_URL/../health

# 2. Register a test user
curl -X POST $BASE_URL/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "full_name": "Test User",
    "email": "test@example.com",
    "phone": "9800000000",
    "password": "testpass123",
    "role": "user"
  }'

# 3. Login
TOKEN=$(curl -X POST $BASE_URL/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "testpass123"
  }' | jq -r '.token')

# 4. Get stocks (public endpoint)
curl $BASE_URL/stocks

# 5. Get profile (protected endpoint)
curl $BASE_URL/auth/profile \
  -H "Authorization: Bearer $TOKEN"

# 6. Get wallet
curl $BASE_URL/wallet \
  -H "Authorization: Bearer $TOKEN"
```

### Expected Results

✅ All endpoints should return valid JSON responses  
✅ No Redis-related errors  
✅ Authentication works correctly  
✅ Database queries execute successfully

## 4. Performance Monitoring

### What to Watch

**Before Redis removal:**
- Rate limiting: 60 req/min per endpoint
- Response caching: 1-2 minutes
- Additional latency: ~5-10ms (Redis lookup)

**After Redis removal:**
- Rate limiting: None (unlimited)
- Response caching: None (direct DB queries)
- Latency: Direct Appwrite queries (~20-50ms)

### Appwrite Dashboard Monitoring

1. Log into [Appwrite Console](https://cloud.appwrite.io)
2. Select your project
3. Navigate to **Overview** → **Statistics**

Monitor:
- **Requests per hour**
- **Database operations**
- **Bandwidth usage**
- **Error rates**

### Setting Up Alerts

If your traffic increases significantly, consider:

1. **Cloudflare Integration:**
   - Free tier includes DDoS protection
   - Built-in rate limiting
   - CDN caching for static responses

2. **Appwrite Alerts:**
   - Set up email notifications for high usage
   - Monitor database query performance
   - Track API response times

## 5. Rollback Plan

If issues arise, you can quickly rollback:

### Option A: Rollback via Git

```bash
# Revert to previous commit
git revert HEAD
git push origin main
```

Render will automatically redeploy the previous version.

### Option B: Manual Restore

1. In Render Dashboard → Your Service → **Deploys**
2. Find the last working deployment
3. Click **Redeploy**

### Option C: Re-enable Redis

If you must restore Redis:

1. **Restore files from git:**
   ```bash
   git checkout <previous-commit-hash> -- pkg/redis pkg/middleware/cache.go pkg/middleware/ratelimit.go
   ```

2. **Update dependencies:**
   ```bash
   go get github.com/redis/go-redis/v9
   go mod tidy
   ```

3. **Restore Redis service in render.yaml**

4. **Commit and push:**
   ```bash
   git add .
   git commit -m "Restore Redis functionality"
   git push origin main
   ```

## 6. Common Issues & Solutions

### Issue: "Cannot connect to database"

**Cause:** Appwrite credentials missing or incorrect

**Solution:**
1. Check environment variables in Render dashboard
2. Verify `APPWRITE_API_KEY` is set correctly
3. Ensure `APPWRITE_PROJECT_ID` and `APPWRITE_DATABASE_ID` match your Appwrite project

### Issue: "401 Unauthorized on protected endpoints"

**Cause:** JWT token issues

**Solution:**
1. Verify `JWT_SECRET` is set in environment variables
2. Try logging in again to get a fresh token
3. Check token is included in `Authorization` header

### Issue: "Slow response times"

**Cause:** No caching, direct database queries

**Solution:**
1. Appwrite has built-in caching - no action needed for most cases
2. For very high traffic:
   - Upgrade Appwrite plan for better performance
   - Use Cloudflare CDN for static content
   - Consider implementing application-level caching

### Issue: "Too many requests from a single user"

**Cause:** No rate limiting

**Solution:**
1. Implement Cloudflare rate limiting (free tier)
2. Or add application-level rate limiting using Appwrite counters
3. Or use Nginx reverse proxy with rate limiting
